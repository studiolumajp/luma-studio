Saily と NordVPN のアフィリエイトリンクを掲載しました

通信の準備をご紹介するページを新設し、Saily (eSIM) と NordVPN (VPN) のアフィリエイトリンク (広告リンク) の掲載を始めました。

通信の準備をご紹介するページ

ご友人や取引先の方が来日される前にお送りいただけるよう、「海外でもつながる通信の準備」というページを用意しました。海外旅行で使える eSIM の Saily と、公衆 Wi-Fi で通信を守る VPN の NordVPN をご紹介しております。

Saily は NordVPN を作った会社の eSIM サービスです。出発前にアプリで設定しておくと、日本に着いた時点でプランが自動で始まります。データ通信はこの eSIM を使い、通話と SMS はふだんの番号のままご利用いただけます。お支払い画面でプロモコード LUMADESIGN をご入力いただくと、10% オフとなります。

NordVPN は通信を暗号化して IP アドレスを隠す VPN サービスで、ホテルや駅、カフェの公衆 Wi-Fi で役立ちます。ブラックフライデーのセール期間となる2026年12月9日までは、NordVPN の契約に3か月の延長特典が付きます。

掲載している場所

LUMA Path のページには、来日するゲストの方へのご案内として、Saily と NordVPN を並べて掲載しております。LUMA Frame のページにも、ご案内のページへ進むための短い文を加えました。

アフィリエイトリンクについて

これらはアフィリエイトリンク (広告リンク) です。リンクからご購入いただくと私どもが紹介料を頂戴しますが、その分お客様のお支払い額が増えることはありません。該当する箇所には「PR」の表示を付けております。詳しくは、特定商取引法・プライバシーポリシー・利用規約のページにある免責事項の8番をご覧ください。
